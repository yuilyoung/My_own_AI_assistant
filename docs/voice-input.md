# 버튼식 한국어 음성 입력

v0.2 구현 계약. STT 기본값은 비활성화이며 고정 demo 응답은 실제 AI가 아니다.

## 데이터 흐름

사용자가 마이크 버튼 선택 → 브라우저 권한 요청 → AudioWorklet PCM 수집 → 녹음 완료 → 16kHz 모노 PCM16 WAV 변환 → 인증된 전사 작업 생성 → 상태 조회 → 결과를 입력창에 표시 → 사용자 확인/수정 후 채팅 전송.

자동 채팅 전송·상시 마이크·외부 API fallback은 없다. whisper.cpp 공식 실행 파일과 다국어 모델은 별도 설치하고 WHISPER_CLI/WHISPER_MODEL을 설정한다. `.en` 모델은 한국어 경로에 사용하지 않는다.

## 제한과 취소

0.1~30초, 최대 WAV 업로드 964096바이트. WAV/RIFF/샘플레이트/채널/PCM 폭/데이터 길이를 검사한다. 정확한 0 신호는 거부하지만 VAD가 아니므로 오인식은 사용자가 확인한다.

최대 작업 수 4개, STT 동시 추론 1개. 다른 세션의 작업은 읽거나 취소할 수 없다. 마이크 승인 대기·녹음·업로드·인식 어느 단계에서든 중지/모드 전환이 기존 결과를 무효화한다. 생성 직후 뒤늦게 반환된 작업도 취소한다.

CLI는 shell 문자열이 아닌 고정 argv로 실행한다. 입력·출력은 임시 폴더에서 처리하고 정상/오류/취소/시간초과 시 삭제한다. 강제 종료 뒤 잔여 파일·디스크 복구까지 막는 보안 삭제는 아니다. 매 발화 모델을 로드하므로 실시간 성능은 아직 보장하지 않는다.

## 수동 검증

Windows 실제 장치에서 마이크 승인/거부·승인 대기 중 취소, 30초 자동 완료, 모드 전환 중 녹음/인식 취소, 한국어 숫자/영문/개발 용어, 잡음/무음, whisper 경로 오류와 모델 오류를 시험한다. 스피커의 AI 음성을 다시 인식하는 에코도 별도 확인한다.

현재 Node/Python 테스트는 상태·포맷·계약·취소를 검증한다. 모의 마이크/실행 파일 테스트는 실제 장치·한국어 모델 시험을 대체하지 않는다.
