# 구현 백로그와 인수 기준

기준일 2026-10-29. 코드는 아직 단계적 반영 대상이며 아래 자동 테스트 수치는 가져올 v0.2 소스에서 재실행한 결과와 구분해 읽는다. 현재 상태는 ../implementation-status.md가 기준이다.

## 이번 커밋 순서

1. README/Read.md와 저장소용 기술 설계·출처·백로그를 먼저 main에 반영한다.
2. 공통 엔진 v0.1을 별도 커밋으로 가져온다. 원본 로컬 커밋: 7410ec7.
3. 버튼식 한국어 음성 입력 v0.2를 별도 커밋으로 가져온다. 원본 로컬 커밋: cc869bd.
4. 원격 트리와 로컬 소스의 blob 해시를 비교하고 테스트 결과·남은 범위를 문서로 기록한다.

새 원격 이력은 문서부터 시작하므로 로컬 원본과 커밋 SHA가 달라진다. 원본의 코드와 테스트 내용은 유지하고 문서의 오래된 업로드 차단 설명은 현재 상태로 정리한다.

## 다음 구현 단위: 실제 캐릭터

- 공식 Cubism Core/Framework와 이용 가능한 고정 모델을 로컬 설치하고 revision·해시·권리를 기록한다.
- React/Vite 화면을 구성한다. 현재 진단 화면을 Live2D로 표시하지 않는다.
- 모델의 motion/expression/LipSync 그룹을 읽어 허용 코드와 매핑한다.
- 실제 음성 재생 시각/RMS를 입 파라미터에 연결하고 중지·모델 언로드에서 리소스를 정리한다.
- 누락된 SDK/모델/동작을 명확히 표시하고 임의 외부 자산을 자동 다운로드하지 않는다.

## 실기기 인수

Windows에서 마이크 승인/거부, 30초 제한, 모드 전환 중 녹음 취소, 한국어 숫자·역명·개발 용어 인식을 확인한다. 실제 Ollama/Melo/whisper 설치·모델 추론, CPU/RAM·cold/warm 지연을 측정한다. 스피커/헤드셋 재생, 30분 대화, 워커 종료/재시작, 반복 세션의 누수·큐 누적을 확인한다.

목표 p50 3초/p95 6초는 측정 목표이며 성공 결과가 아니다. 단위 테스트 통과는 마이크·모델·캐릭터 통합 시험을 대체하지 않는다.
