## 자동 검증 점수

[기술 설계서 11절](technical-design.md)의 필수 소프트웨어 시험 8개는 Python 개발 의존성과 Node.js를 설치한 환경에서 `python scripts/check_acceptance.py`로 검사한다. 항목당 12.5점이며 목표는 70점이다. Python은 모듈·테스트 이름·매개변수 사례 ID를, Node는 진단 테스트 파일과 테스트 이름을 대조한다. 필수 사례가 하나라도 누락되거나 건너뛰거나 실패하면 해당 항목은 0점이다. 점수와 항목별 필수 사례를 JSON으로 출력하며, 전체 Python·Node 테스트가 실패하거나 점수가 70점 미만이면 종료 코드 1을 반환한다. 아래 실기기 인수와 운영 배포는 별도 확인이 필요하다.

## 완성 전에 남은 필수 범위

1. 내장 캐릭터 3종의 원화 유지, 눈 깜빡임·호흡·고개 움직임·표정 전환·입모양을 실제 화면에서 확인한다.
2. 실제 한국어 LLM/STT/TTS 및 물리 마이크·스피커로 음성 품질·지연·중지/모드 전환 시 입 닫힘을 검증한다.
3. React 운영 빌드, 기억·권한 격리, formatter/lint/타입 검사/단위·E2E 테스트 및 산출물 CI를 검증한다.
4. 사용자 Windows PC에서 30분 대화, 반복 세션·워커 재시작·리소스 해제를 기록한다.

합성 STT/TTS 브라우저 검증과 자동 채점은 실제 모델·실기기 인수를 대체하지 않는다. 모든 필수 기능의 실제 동작 증거가 있어야 MVP 완료다.

## 선택적 확장: Cubism

공식 SDK/Core 및 사용권 확인 모델 확보, 실제 WebGL 렌더러 및 motion/expression/LipSync 매핑은 내장 MVP 이후 선택 가능하다. 기존 어댑터 계약은 유지한다. SDK·모델 미설치는 MVP 차단 요인이 아니다. [자산 전달 안내](../live2d-asset-handoff.md).

## MVP 이후

VAD, WebSocket/문장 스트리밍, 상주 STT 워커, 할 일 관리, 데이터 삭제·백업, Codex 작업별 승인, Mac mini ARM64 이전·HTTPS·원격 인증. 인터넷 공개·다중 사용자 서비스는 현재 로컬 MVP 범위 밖이다.
